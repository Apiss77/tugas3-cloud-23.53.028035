Devlog NATA

Catatan pengembangan asisten AI lokal NATA, ditulis per sprint. Klik sebuah entri untuk membuka rinciannya.

Catatan

Dari yang terbaru ke awal

Sprint 6

Sistem pengetahuan dan dokumen

Berikutnya
  • Pemuat dokumen untuk Markdown, teks, dan PDF
  • Pemecahan dokumen menjadi potongan (chunking) agar mudah dicari
  • Hybrid retrieval: pencarian gabungan atas memori dan dokumen
Sprint 4–5

Audit, stabilisasi, dan integrasi

Selesai
  • Audit dan perbaikan dituangkan dalam laporan STABILIZATION_SPRINT_4_5_REPORT.md
  • SQLite: foreign key diaktifkan pada setiap koneksi, pengambilan metadata memori diperbaiki, dan fakta lama diarsipkan
  • Perhitungan MRR pada evaluasi retrieval diperbaiki, dan Memory Retriever kini memakai metadata SQLite
  • Penalti memori kedaluwarsa pada Memory Reasoner dan filter preferensi pada Personalizer diperbaiki
  • Bounded retry pada Task Executor, keamanan berkas pada Tool Registry, dan dispatch /task pada Chat Engine diperkuat
  • Hasil pengujian akhir: 215 dari 215 tes lolos (25 berkas pengujian, 24,39 detik)
Sprint 5Okt 2026

Sistem agentik: perencana tugas dan tool aman

Selesai
  • Task Planner memecah tujuan menjadi langkah-langkah, berbentuk graf alur kerja (DAG)
  • Task Executor menjalankan langkah lewat Tool Registry dengan tool read-only di dalam sandbox
  • Task Store menyimpan status tugas, dilengkapi bounded retry dan pemulihan setelah crash
  • Tool Safety melindungi berkas sensitif dan mencegah akses keluar dari workspace
  • Tugas dipicu secara eksplisit lewat /task, sehingga percakapan biasa tidak otomatis menjalankan tool
  • Rilis versi 0.5.0-alpha
  • Catatan: audit lanjutan menemukan keterbatasan pada dispatch agent, jadi komponen agent belum berarti agent otonom yang lengkap
Sprint 4.3

Pencarian memori semantik

Selesai
  • Pencarian memori naik kelas dari pencocokan kata kunci ke vector embeddings (all-MiniLM-L6-v2 dengan ChromaDB)
  • Perbaikan MemoryRepository berbasis SQLite: upsert lewat ON CONFLICT dan penutupan kebocoran koneksi
  • Model embedding multibahasa (multilingual-e5-small) dicatat untuk dievaluasi kemudian
Sprint 4

Memori yang lebih cerdas

Selesai
  • Confidence evaluation: menilai tingkat kepercayaan informasi dari sumber dan status verifikasinya
  • Memory provenance: mencatat asal-usul informasi yang tersimpan
  • Temporal memory: fakta yang berubah dipindahkan ke riwayat dengan status superseded, bukan dihapus
  • Memory Reasoner dan preference personalization untuk memilih informasi yang layak dipakai dalam konteks
  • Benchmark pencarian memori secara offline dengan Precision@K, Recall@K, dan MRR
Sprint 3.5

Stabilisasi arsitektur

Selesai
  • Masalah yang ditemukan: output Qwen3 dengan tag <think> merusak ekstraksi JSON, startup tidak lewat Application, implementasi embedding dan ChromaDB terduplikasi, serta path database bergantung pada working directory
  • Perbaikan: lifecycle Application, pembersihan tag <think> dan JSON fence, penggabungan layanan duplikat, dan fallback metadata lama pada ChromaDB
  • Automated test suite pertama: 42 dari 42 tes lolos dalam 8,81 detik
  • Baseline pengembangan 0.3.5 (bukan rilis resmi GitHub)
Sprint 3

Memori persisten

Selesai
  • Fakta penting tentang pengguna disimpan permanen dan bisa dipakai di percakapan berikutnya
  • Penyimpanan ganda: SQLite untuk data terstruktur dan ChromaDB untuk representasi vektor
  • Pencarian semantik dengan SentenceTransformer, dilengkapi Memory Extractor, Writer, Retriever, dan Reasoner
  • Milestone versi 0.3.0
Sprint 2

Memori sesi

Selesai
  • NATA mempertahankan konteks percakapan dalam satu sesi lewat Session Manager dan riwayat percakapan
  • Pesan pengguna dan respons asisten disimpan, lalu dikirim sebagai konteks ke LLM
  • Menjadi dasar sebelum dikembangkan menjadi memori jangka panjang
  • Milestone ditandai tag v0.2.0
Sprint 118 Apr 2026

Fondasi proyek

Selesai
  • NATA dimulai sebagai AI companion lokal dan offline berbasis Python, dengan Ollama dan model Qwen
  • Percakapan dasar lewat antarmuka terminal (CLI), dengan identitas NATA ditentukan lewat system prompt
  • Arsitektur modular dengan 8 modul inti dan sistem memori 4 lapis
  • Stack awal: Python, Ollama, dan SQLite
