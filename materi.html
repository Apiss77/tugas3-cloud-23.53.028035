Materi Komputasi Awan

Ringkasan konsep dasar cloud computing, tiga model layanan utama, serta manfaat dan risiko penggunaannya.

Pengertian Komputasi Awan

Komputasi awan (cloud computing) adalah model penyediaan sumber daya komputasi seperti server, penyimpanan, basis data, jaringan, dan perangkat lunak melalui internet, yang dapat digunakan sesuai kebutuhan dan dibayar sesuai pemakaian. Pengguna tidak perlu membeli dan merawat perangkat keras sendiri karena infrastrukturnya dikelola oleh penyedia layanan, misalnya Google, Microsoft, Amazon, atau GitHub.

Ciri utamanya meliputi akses mandiri sesuai permintaan, dapat diakses dari mana saja melalui jaringan, sumber daya yang dibagi bersama banyak pengguna, kemudahan menambah atau mengurangi kapasitas, serta penggunaan yang dapat diukur.

Model Layanan: SaaS, PaaS, IaaS

SaaS

Software as a Service

Aplikasi jadi yang langsung dipakai lewat browser atau aplikasi, tanpa mengurus server maupun instalasi. Pengguna hanya memakai fiturnya.

Contoh: Google Drive, Gmail, Microsoft 365.

PaaS

Platform as a Service

Platform siap pakai bagi pengembang untuk membangun, menjalankan, dan mengelola aplikasi tanpa mengurus server dan sistem operasi di bawahnya.

Contoh: Google App Engine, Heroku, Vercel, GitHub Pages (hosting website statis).

IaaS

Infrastructure as a Service

Penyedia menyewakan infrastruktur dasar berupa mesin virtual, penyimpanan, dan jaringan. Pengguna mengatur sendiri sistem operasi dan aplikasinya.

Contoh: Amazon EC2, Google Compute Engine, Azure Virtual Machines.

Manfaat dan Risiko

Manfaat

  • Hemat biaya: tidak perlu membeli perangkat keras, cukup bayar sesuai pemakaian.
  • Skalabel: kapasitas mudah ditambah atau dikurangi saat kebutuhan berubah.
  • Mudah diakses: dapat dibuka dari mana saja dan dari berbagai perangkat.
  • Ketersediaan tinggi: layanan tetap aktif walau laptop pengguna dimatikan.
  • Pemeliharaan oleh penyedia: pembaruan dan pencadangan ditangani penyedia layanan.
  • Kolaborasi: banyak orang dapat bekerja pada berkas atau proyek yang sama.

Risiko

  • Privasi dan keamanan data: data disimpan di server pihak lain sehingga berisiko bocor jika konfigurasi salah.
  • Ketergantungan internet: layanan tidak dapat diakses tanpa koneksi.
  • Vendor lock-in: sulit berpindah penyedia setelah terlanjur bergantung pada satu layanan.
  • Gangguan layanan: bila penyedia mengalami gangguan, pengguna ikut terdampak.
  • Kontrol terbatas: pengguna tidak sepenuhnya mengatur infrastruktur dan kebijakannya.
  • Biaya tak terduga: pemakaian berlebih dapat membuat tagihan membengkak.
