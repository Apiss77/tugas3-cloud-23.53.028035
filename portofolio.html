TUGAS 3

Deployment Website Menggunakan GitHub Pages

Website statis ini dipublikasikan melalui GitHub Pages dari repositori publik. Setiap perubahan yang di-commit ke branch utama otomatis diterapkan pada URL yang sama, sehingga pembaruan versi dapat dibuktikan tanpa berganti alamat.

Alur Deployment

  1. SiapkanBuat 3 halaman dan uji secara lokal.
  2. UnggahBuat repositori publik dan commit berkas.
  3. Aktifkan PagesPilih branch utama dan folder utama.
  4. Verifikasi V1Buka URL publik di jendela privat.
  5. Perbarui V2Ubah satu unsur, commit, muat ulang URL yang sama.
